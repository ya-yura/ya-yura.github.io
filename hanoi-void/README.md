# HANOI//VOID

Автономная браузерная игра на базе Ханойских башен с плоской мультяшной графикой в духе мобильных puzzle-игр: толстые контуры, яркие «конфетные» диски, мягкие тени, бумажный фон и дружелюбные эффекты. Для запуска не нужны CDN, сборщик или внешние сервисы.

## Запуск

Из корня проекта:

```powershell
npm run dev
```

Открыть [http://127.0.0.1:4321/hanoi-void/](http://127.0.0.1:4321/hanoi-void/).

Игра также нормально живёт как статическая папка на любом сервере. Состояние, текущий seed, рекорды и инструменты сохраняются в `localStorage` браузера.

## Что внутри

- Бесконечный генератор уровней: растёт число дисков, стержней, длина перемешивания и сложность аномалий.
- Плоское графическое поле: контурные стержни, конфетные диски, бумажная текстура фона, декоративные дуги, частицы и рифт-стержень.
- Игровые инструменты: `REWIND`, `SCAN`, `QUANTUM`, `STASIS`.
- Несколько аномалий: стабильное ядро, рифт, эхо-цикл и ускоренный void surge.
- Автосохранение и восстановление незавершённого сектора.
- Управление мышью/тачем, клавишами `1–6`, `R`, `Z`, `Space`.
