# Portfolio Site

Дата обновления: 2026-06-16
Статус: текстовая публичная онлайн-версия для поиска работы.

## Назначение

Эта версия должна работать без визуалов. Рекрутер, арт-директор, дизайн-лид, тимлид или продакт-менеджер должны быстро понять:

- кто такой Юрий Пылёв;
- в каких продуктах он силён;
- какие задачи умеет решать;
- какую пользу даёт пользователю, бизнесу и команде;
- почему его стоит позвать на разговор.

## Что изменено

- Сайт переведён в полностью текстовый формат: в публичных HTML нет изображений, мета-картинок, визуальных превью и декоративных заглушек.
- Главная переписана как рекрутинговая страница: сильный первый экран, ценность для нанимающей команды, кейсы, подход, опыт и контакт.
- Все кейсы поданы через задачу, ставку, решение, пользу и проверку эффекта.
- Убрана служебная разметка, внутренний аудит, технический шум и лишние англоязычные маркеры.
- `about.html`, `cv.html`, `evidence.html` и четыре кейса приведены к единому убедительному тону.

## Страницы

- `index.html` — главная публичная страница.
- `cases/sklad-15.html` — складская приёмка от сканирования.
- `cases/industrial-data-platform.html` — промышленная платформа: объект, карта, документы.
- `cases/thermal-camera.html` — интерфейс устройства: режимы и доверие к измерению.
- `cases/ruchamp.html` — спортивное событие как управляемый процесс.
- `about.html` — профессиональная позиция и как читать портфолио.
- `cv.html` — резюме, опыт, контакт.
- `evidence.html` — почему публичная версия текстовая и как читать кейсы.

## Как открыть

Открыть `index.html` напрямую в браузере. Dev server не нужен.

## Принцип подачи

Публичная версия продаёт опыт, мышление и зрелость без неподготовленных картинок. Визуалы продолжают готовиться локально и могут быть добавлены позже, когда будут готовы к публичной публикации.
